# Rendered loop

`rendered-loop.png` is a frozen 512 × 288 capture of the actual default 3D loop from the local application's Three.js renderer, before any Look processing. It was captured on September 11, 2026. The model's geometry was not redrawn or substituted.

The thumbnail generator uses this image only for the fixed 3D gradient examples. GPU regression fixtures still use the synthetic sphere to make position, source color and auxiliary-plane comparisons reproducible.
